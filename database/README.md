# ข้อมูลฐานข้อมูล (Database Documentation) - ร้านตำครกซิ่ง (Tum Krok Zing)

## 1. ไฟล์ฐานข้อมูลหลักสำหรับส่งงาน / นำเข้า (Database Script)
- **`tum_krok_zing.sql`** : ไฟล์ SQL Dump ฉบับสมบูรณ์ (สร้างฐานข้อมูล `tum_krok_zing`, สร้างตารางทั้ง 13 ตาราง, ข้อมูลเริ่มต้น/Seed Data ทั้งหมด, และ Database Views ทั้ง 5 ตัว)

### วิธีการนำเข้าฐานข้อมูล (Import)
#### ผ่าน Command Line:
```bash
mysql -u root -p < database/tum_krok_zing.sql
```
#### ผ่าน phpMyAdmin / MySQL Workbench / DBeaver:
1. เปิดเครื่องมือเชื่อมต่อฐานข้อมูล MySQL
2. ไปที่เมนู **Import** หรือเปิดไฟล์ `database/tum_krok_zing.sql`
3. กด **Execute / Go** ระบบจะสร้างฐานข้อมูล `tum_krok_zing` พร้อมตาราง, วิว และข้อมูลทั้งหมดโดยอัตโนมัติ

## 2. โครงสร้างตารางหลักตามเล่มรายงาน (12 Core Tables)
ตารางหลักตามพจนานุกรมข้อมูล (Data Dictionary) และแบบจำลอง ER-Diagram ในเล่มรายงาน มีทั้งหมด **12 ตาราง**:
1. **`USERS`** - ข้อมูลผู้ใช้งานระบบ (Admin, Staff, Customer)
2. **`TABLES`** - ข้อมูลโต๊ะอาหารภายในร้าน (ความจุ และสถานะ เช่น AVAILABLE, OCCUPIED)
3. **`CATEGORIES`** - หมวดหมู่อาหาร (อาหารอีสาน, ต้ม/แกง, ทอด/ย่าง, ยำ, เครื่องดื่ม)
4. **`MENUS`** - เมนูอาหาร ราคา และรูปภาพ
5. **`ALLERGENS`** - ข้อมูลสารก่อภูมิแพ้
6. **`MENU_ALLERGENS`** - ความสัมพันธ์เมนูอาหารกับสารก่อภูมิแพ้
7. **`INGREDIENTS`** - คลังวัตถุดิบ จำนวนคงเหลือ หน่วยนับ และจุดสั่งซื้อซ้ำ (Reorder Level)
8. **`MENU_INGREDIENTS`** - สูตรอาหารและการตัดสต็อกวัตถุดิบต่อเมนู
9. **`PROMOTIONS`** - โค้ดส่วนลดและโปรโมชั่น
10. **`ORDERS`** - รายการคำสั่งซื้อของลูกค้า/โต๊ะ
11. **`ORDER_ITEMS`** - รายการอาหารย่อยในแต่ละออเดอร์
12. **`TRANSACTIONS`** - การชำระเงินและประวัติสลิปโอนเงิน

*(หมายเหตุ: ในระบบจริงมีตารางเสริมระดับแอปพลิเคชัน 1 ตาราง คือ `STORE_SETTINGS` ใช้สำหรับเก็บสถานะเปิด/ปิดร้านและเลข PromptPay ของหน้า Admin)*

## 3. ฐานข้อมูลวิว (Database Views - 5 วิว)
1. **`ORDER_SUMMARIES_VIEW`** - สรุปยอดขายและสถานะคำสั่งซื้อ
2. **`TRANSACTION_RECEIPTS_VIEW`** - สรุปใบเสร็จและการชำระเงิน
3. **`TOP_SELLING_MENUS_VIEW`** - สถิติเมนูยอดนิยมและรายได้ตามเมนู
4. **`LOW_STOCK_ALERTS_VIEW`** - แจ้งเตือนวัตถุดิบใกล้หมดสต็อก
5. **`LIVE_TABLE_STATUS_VIEW`** - สถานะโต๊ะอาหารและออเดอร์ปัจจุบันแบบเรียลไทม์
